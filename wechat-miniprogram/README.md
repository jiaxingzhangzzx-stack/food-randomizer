# 今天吃什么微信小程序版

这是网页版美食摇号的微信小程序源码版本。

## 使用方式

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`wechat-miniprogram`。
4. 没有正式 AppID 时可以先使用测试号预览；要上传发布，需要把 `project.config.json` 里的 `appid` 换成你自己的小程序 AppID。

## 已迁移功能

- 全部 / 聚餐 / 外卖 / 单人餐 / 食堂分类摇号
- 手动输入编号查看
- 最近摇到记录
- “确认”后才累计已吃次数
- 已吃次数使用小程序本地缓存保存
- 原生 `map` 组件显示店铺所在区域
- `wx.openLocation` 打开微信地图查看位置

## 注意

当前小店位置主要按“龙湖时代天街、南门、食堂、商业街、配送到校”等区域聚类。后续如果你给出更准确的店铺坐标，可以逐家替换成精确定位。
